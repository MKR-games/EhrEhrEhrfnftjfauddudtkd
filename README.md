# 똑... 똑... 똑... — 모션 그래픽 룰 영상

**가로 16:9 / 1920×1080 / 30fps / 5분 / 9,000프레임**

2026-10-07 디자인 개편본입니다. 나레이션 없이 텍스트, 배경음, 효과음으로 게임 규칙을 설명합니다.

## 디자인과 모션

참조 영상 《더 지니어스: 가넷도둑 룰 영상》의 가로 화면 구성, 상단 타이틀 장식,
인물 아이콘과 카드 배치, 선택·분배·공개를 시각화하는 방식을 참고했습니다.

- 검정·금색 타이틀과 차분한 베이지 배경
- 서로 다른 색과 외형을 가진 다섯 인물 아이콘
- 조사 카드와 소지품의 색 구분
- 카드의 곡선 이동, 순서별 등장, 회전, 뒤집기
- 공개·비공개·선택 제한을 구분하는 아이콘과 강조 색
- 음악의 박자와 행동에 맞춘 카드·종이·노크 효과음

이 버전은 매끈한 벡터 모션 그래픽입니다. 이전 버전의 붓질, 가로 스캔선, 라인 보일링은
적용하지 않습니다. 모든 그림은 JavaScript Canvas로 매 프레임 다시 계산해 그립니다.
삽입 이미지, 외부 영상, 스프라이트, 생성 영상은 사용하지 않습니다.
참조 영상의 로고, 실제 화면, 음악, 효과음은 포함하지 않습니다.

## 바로 재생하기

`똑똑똑_룰영상_JS재생.html`을 브라우저에서 열고 **재생**을 누르세요.
글꼴과 음악이 포함되어 있어 인터넷 없이 재생할 수 있습니다.

재생·일시 정지, 장면 선택, 시간 이동, 0.75–1.5배 속도, 음량, 전체 자막 읽기를 지원합니다.
휴대폰에서는 가로 전체 화면으로 보는 것을 권장합니다. 로컬 HTML 실행이 제한되는 앱에서는
함께 제공된 MP4로 시청하세요.

## 규칙 근거

2026년 9월 30일 인쇄용 PDF 묶음에 포함된 게임 설명서의 **2026.09.20 수정본** 기준입니다.
조사 카드 13장 + 개인 소지품 카드 5장 = 조사 가능 카드 18장.
제1막은 10장 전체 공개, 제2막은 5장 개인 확인, 나머지 3장은 미선택입니다.

구성물, 준비, 오프닝, 대화의 경계, 두 막의 조사·논의, 미선택 카드, 최종 추리,
투표·동률, 엔딩, 선택 점수 규칙을 담았습니다. 캐릭터 비밀과 사건의 해답은 수록하지 않았습니다.
이야기의 배경 전문과 첫 진술은 실제 게임의 오프닝에서 읽어 주세요.
그림 속 카드와 점수 도표는 규칙을 설명하기 위한 예시입니다.

## 파일 구성

- `src/storyboard.js`: 30개 장면의 자막과 구성. 장면당 10초.
- `src/engine.js`: 모든 인물·카드·아이콘·배경·모션 렌더링.
- `player.template.html`: 오프라인 재생기의 화면과 제어.
- `make_audio.py`: 원본 음악과 효과음 생성. 음성/TTS/외부 샘플 없음.
- `audio/soundtrack.m4a`: 완성 스테레오 음악·효과음.
- `audio/events.json`: 효과음 타임코드.
- `render.mjs`: Canvas를 FFmpeg에 전달해 영상 구간 출력.
- `export_all.py`: 변경 감지, 구간별 재개, 최종 MP4 조합.
- `build.py`: 음악·글꼴·JS를 포함한 단일 HTML 생성.

## 다시 출력하기

Node.js, Python 3, FFmpeg가 필요합니다.

```sh
npm install
python3 -m pip install -r requirements.txt
python3 make_audio.py
python3 build.py
node render.mjs preview
python3 export_all.py
```

완성본은 `dist` 폴더에 저장됩니다. `build.py`와 `export_all.py`의 첫 번째 인자로
다른 출력 폴더를 지정할 수 있습니다. 영상은 30초씩 순차 출력하며 진행 상황을 저장합니다.
소스가 바뀌면 이전 영상 구간을 다시 출력합니다. `RENDER_WIDTH=1280`으로 720p 출력을
선택할 수도 있습니다. 영상 길이는 300초, 프레임률은 30fps입니다.
